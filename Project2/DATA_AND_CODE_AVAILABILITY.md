# Data and code availability

The repository contains no individual-level participant data. Individual-level
HELIOS data and provider-controlled GWAS summary statistics cannot be
redistributed through GitHub. Access is subject to the ethics, data-use and
provider requirements described in the manuscript.

The custom analysis code is available at
<https://github.com/TimvanderEs/PhD/tree/main/Project2>. The repository also
contains configuration files, run manifests, checksums, synthetic examples and
non-sensitive derived results. Third-party software must be obtained from the
sources cited in the workflow documentation.

The publication version will be identified by a GitHub release and archival
DOI. Until then, the relevant Git commit identifies the code version.
