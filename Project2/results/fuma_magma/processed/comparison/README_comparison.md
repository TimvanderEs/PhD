# MAGMA single-trait and PLEIO comparison

The tables in this directory compare corrected positive enrichments from each
PLEIO model with the available constituent single-trait analyses.

- `PLEIO_shared_with_available_constituent`: significant in PLEIO and at least
  one available single-trait analysis
- `PLEIO_only_among_available_constituents`: significant in PLEIO only
- `constituent_only`: significant in at least one single-trait analysis only
- `neither`: not significant in either analysis

EAS comparisons involving cognitive function are incomplete because an EAS
cognitive-function single-trait SNP2GENE result was unavailable. These labels
describe significance patterns; they do not establish biological specificity
or causality.
