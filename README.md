# PhD research code

Analysis code and reproducibility material from my PhD research at King's
College London and A*STAR Singapore.

| Project | Repository contents |
| --- | --- |
| [Project 1](project1/) | Project 1 analysis material |
| [Project 2](Project2/) | Cross-ancestry analyses of major depression, schizophrenia, educational attainment and cognitive function |
| [Project 3](Project3/) | HELIOS 10k cognitive GWAS and Chinese–Indian–Malay meta-analysis |

Each project directory describes its data-access conditions, software
requirements and reproducibility scope. No individual-level participant data
are stored in this repository.
