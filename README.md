# PhD research code

Analysis code and reproducibility material from my PhD research at King's
College London and A*STAR Singapore.

| Project | Repository contents |
| --- | --- |
| [Project 1](project1/) | Local genetic correlation and colocalisation of major depression with intelligence and educational attainment; overview and COLOC-reporter reference |
| [Project 2](Project2/) | Cross-ancestry analyses of major depression, schizophrenia, educational attainment and cognitive function |
| [Project 3](Project3/) | HELIOS 10k cognitive GWAS and Chinese–Indian–Malay meta-analysis |
| [Project 4](Project4/) | Chapter 3, Study 2: Singapore LD reference panels, controlled LDSC comparisons and reproducible workflows |

Project 1 links to the external analysis software. Projects 2–4 contain analysis
code and supporting documentation, with data-access conditions and
reproducibility scope described in their project directories. No individual-level
participant data are distributed here.

For the LD-reference work in Chapter 3, start with the
[Project 4 overview](Project4/README.md), the
[chapter-to-code guide](Project4/CHAPTER3_GUIDE.md), or the
[synthetic workflow example](Project4/portable/README.md).
