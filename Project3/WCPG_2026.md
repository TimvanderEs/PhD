# WCPG 2026 poster resources

## Lessons and challenges of trans-ancestry cognitive GWAS in the HELIOS cohort

The poster presents the expanded HELIOS cognitive phenotype and ancestry-specific
GWAS in Chinese, Indian and Malay participants.

## Main results

| Metric | Result |
|---|---:|
| Cognitive PCA sample | 22,422 |
| PC1 variance explained | 37.04% |
| Chinese GWAS | 17,966 |
| Indian GWAS | 2,310 |
| Malay GWAS | 1,242 |
| Total ancestry-specific GWAS sample | 21,518 |
| Raw METAL variants | 10,286,285 |
| Retained METAL variants | 6,518,064 |
| Genome-wide significant variants | 0 |
| Minimum retained P | 6.906 × 10⁻⁷ |
| Poster SNP heritability | 0.0392 (SE 0.0202) |

The six-task PC1 was led by Stroop Box (0.551), Stroop Ink (0.486) and
Reaction Time (0.439). Quiz Score, Working Memory and Pairing Guesses had
loadings of 0.323, 0.314 and 0.254. These are sign-oriented so that higher
scores indicate better performance.

## Analysis

Six cognitive tasks were aligned, residualised and combined using PCA. GWAS
was then run separately in the three ancestry groups with REGENIE 4.1. Before
association testing, PC1 values beyond five within-group standard deviations
were set to missing and the remaining scores were Blom inverse-normal
transformed within ancestry. REGENIE Step 2 received this transformed score and
did not apply a second RINT. The results were combined using a fixed-effect
inverse-variance METAL model.
Retained variants had `HetDf >= 1`, `HetPVal > 0.05` and a maximum
between-ancestry allele-frequency difference below 0.5.

This use of “trans-ancestry meta-analysis” refers to the fixed-effect
combination of ancestry-specific GWAS results. It is not an explicit model of
ancestry-heterogeneous effects.

## Interpretation notes

- The stored 22k PC1 has the arbitrary opposite sign, so higher stored values
  indicate poorer performance. Sign reversal changes loading and association
  effect directions, but not P values or model fit.
- The raw top METAL marker was represented in only one ancestry (`HetDf = 0`)
  and was therefore removed by the retained two-ancestry filter.
- The historical 10k analysis and the expanded 22k analysis are separate
  records. Their heritability estimates should not be treated as a sample-size
  scaling experiment.
- The post-PCA inverse-normal transformation is distinct from task
  transformations and residualisation performed before PCA.

The poster heritability value comes from the archived 22k LDSC record. Its log
does not retain the exact LD-score path. A later matched rerun using the frozen
SG100K 20 cM cov-LDSC reference gave h² = 0.0394 (SE 0.0188). See the
[genetic-signal audit](validation/22k/03_genetic_signal/genetic_signal_audit.md).
