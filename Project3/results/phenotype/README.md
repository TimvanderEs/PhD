# Cognitive-factor results

These tables contain aggregate results from the reproduced HELIOS 10k
six-task PCA:

- `pca_summary.tsv`: sample size, variance explained and validation against the
  saved historical score;
- `pca_loadings.tsv`: component loadings and task-score correlations; and
- `task_correlations.tsv`: correlations among the six residualised PCA inputs.

The columns labelled `stored_g` use the sign of the historical phenotype,
where higher values indicate poorer performance. The `higher_performance`
columns reverse the arbitrary PCA sign for presentation. No participant-level
scores are included.
