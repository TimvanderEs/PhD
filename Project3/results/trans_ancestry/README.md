# Trans-ancestry results

`meta_analysis_manifest.tsv` identifies the two recovered 10k
Chinese–Indian–Malay meta-analysis iterations. The full summary statistics are
not stored in this repository; the checksums identify the validated files.

Both files use the same METAL schema and passed the retained filters:

- representation in at least two ancestry groups;
- heterogeneity P > 0.05; and
- maximum allele-frequency difference < 0.5.

The ancestry-specific sample sizes in the manifest are the largest
variant-level values encoded in each result, not cohort enrolment counts.
