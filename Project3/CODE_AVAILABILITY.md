# Code availability

Suggested manuscript wording:

> Custom analysis, post-processing, and figure-source code is available at
> [https://github.com/TimvanderEs/PhD/tree/main/Project3](https://github.com/TimvanderEs/PhD/tree/main/Project3).
> The repository includes privacy-safe synthetic test data, analysis
> configurations, archived non-controlled enrichment results, checksums, and
> workflow-specific provenance. Source GWAS summary statistics and reference
> panels are not redistributed and must be obtained from the providers cited in
> the manuscript. The exact reviewed version is identified by its Git commit.

This wording distinguishes code availability from controlled-data
availability. When the LAVA verification is complete, create an immutable
GitHub release and archive it with Zenodo or an equivalent repository. The
release DOI can then replace or accompany the branch URL without changing the
scope statement.
