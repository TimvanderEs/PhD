# Controlled reference-panel results

These are the reader-facing aggregate tables from the final controlled Singapore LD-reference experiment.

- `controlled_h2_panel_summary.tsv`: panel-level h2, SE, h2/SE, and intercept means.
- `controlled_h2.tsv`: six trait-level h2 estimates for each of five panels.
- `paired_h2_differences.tsv`: covariance-aware paired jackknife comparisons with BH correction within each six-trait contrast.
- `controlled_rg.tsv`: all 75 genetic-correlation estimates.
- `controlled_rg_concordance.tsv`: concordance between each Singapore panel and exact 1KG EAS.
- `reference_size_*.tsv`: Chinese reference-size sensitivity.
- `simulation_*.tsv`: five held-out calibration simulations.

The full design, logs, QC records, and interpretation are in [`../../validation/controlled_reference_experiment/`](../../validation/controlled_reference_experiment/).
